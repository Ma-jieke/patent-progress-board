# PatentFlow 修复：删除成果与自定义代理机构

## 删除成果
1. 使用管理员身份登录。
2. 打开任意成果详情，点击「删除此成果」；也可以在「编辑成果及负责人」窗口中删除。
3. 阅读永久删除提示、点击确定。
4. 在二次确认框手动输入「删除」两个字，再确认。
5. 后端再次检查管理员会话、同源请求、成果 ID、名称及版本，确认后执行数据库删除。
6. 相应的节点负责人和状态历史由 D1 数据库的外键 `ON DELETE CASCADE` 一并移除；人员名录不会清空。

**重要：该功能是永久删除，界面没有撤销。误删后如有数据库 Time Travel 恢复需求，应在保留期限内谨慎处理。**
未经管理员登录的普通查看用户无法删除。

## 代理机构
1. 原有「安徽阜梦」「北京荟英」继续保留为快捷选项。
2. 选择「其他机构（自行填写）」后，在展开的输入框里填写机构完整名称。
3. 保存后，该名称存入原 `patents.agency` 字段，无需数据库结构升级。
4. 此后其他成果的代理机构下拉菜单会自动包含已登记机构，方便重复选择。
5. 旧专利的代理机构名称保持不变，软件著作权仍显示「不适用」。

## 上线
修改只涉及前端 `site/index.html`、代理机构校验 `functions/_lib/patent-v2.ts`、删除 API `functions/api/patents/[id].ts`。合并到 main 后 Cloudflare Pages 将自动构建。**不用在 D1 Console 执行任何 SQL，也不需要修改管理员密码。**

## 建议验收
- 以普通访客查看：没有删除按钮。
- 管理员打开记录：详情与编辑页都能找到删除入口。
- 取消首次确认、二次确认不输入「删除」：记录不应改变。
- 新增成果时输入其他代理机构，保存后刷新仍存在、下次下拉框可选择。
- 如需测试实际删除，先创建一条名为「删除功能测试（可删除）」的临时成果，并仅删除这条测试数据。
